# rshell

Переносимая конфигурация zsh и минималистичный менеджер плагинов на основе
[zsh_unplugged](https://github.com/mattmc3/zsh_unplugged).

- Переносимое ядро (`zshrc`) отделено от настроек конкретной машины (`~/.zshrc`).
- Плагины не хранятся в репозитории — клонируются при первом запуске zsh.
- Никаких субмодулей и внешних зависимостей, кроме `git` и `zsh`.

## Структура

```
rshell/
├── zshrc            # переносимое ядро: env, опции, клавиши, compinit, промпт, plugin-load
├── zshrc.template   # шаблон хост-файла ~/.zshrc
├── install.sh       # установка/удаление ~/.zshrc
├── LICENSE          # MIT
├── NOTICE           # атрибуция стороннего кода
├── README.md
└── plugins/         # рантайм-кэш плагинов (в .gitignore, клонируется при запуске)
```

| Файл | Назначение |
|------|------------|
| `zshrc` | Общая для всех машин конфигурация. Здесь задаются опции, привязки, дополнения, промпт и функция `plugin-load`. |
| `zshrc.template` | Шаблон `~/.zshrc`: подключает `zshrc` репозитория, объявляет плагины и оставляет место для локальных настроек. Плейсхолдер `@RSHELL_DIR@` заменяется `install.sh` на путь к репозиторию. |
| `install.sh` | Готовит `~/.zshrc` из шаблона, делает бекап и при необходимости копирует репозиторий в XDG-каталог. |

Каталог плагинов по умолчанию:
`${XDG_DATA_HOME:-$HOME/.local/share}/rshell/plugins` (задаётся переменной `ZPLUGINDIR`).

## Требования

- `zsh`
- `git` — для загрузки плагинов
- `bash` — для `install.sh`

## Установка

Репозиторий рекомендуется держать в `${XDG_DATA_HOME:-$HOME/.local/share}/rshell`:

```sh
git clone <url> "${XDG_DATA_HOME:-$HOME/.local/share}/rshell"
"${XDG_DATA_HOME:-$HOME/.local/share}/rshell/install.sh"
```

Если репозиторий лежит в другом месте, `install.sh` предупредит и предложит
скопировать его в рекомендованный XDG-каталог. Если отказаться, `~/.zshrc`
будет ссылаться на текущее расположение репозитория.

Существующий `~/.zshrc` сохраняется как `~/.zshrc.bak` (бекап создаётся только
один раз — уже существующий не перезаписывается). Плагины будут загружены при
первом запуске zsh.

Опции `install.sh`:

```
--uninstall   удалить установленный ~/.zshrc (и восстановить бекап)
--help, -h    справка
--version, -v версия
```

После установки перезапустите терминал или выполните `exec zsh`.

## Конфигурация

- Настройки **для всех машин** — в `zshrc`: окружение, опции (`setopt`),
  привязки (`bindkey`), дополнения, промпт.
- Настройки **конкретной машины** — в `~/.zshrc` (секция `HOST-SPECIFIC`):
  пути, секреты, специфичные для хоста переменные.

Промпт задаётся функцией `_get_prompt` в `zshrc` и использует цвета
`C_RESET`, `C_RARROWS`, `C_LARROWS`, `C_OPERATOR`, `C_OPERAND`, `C_ERROR` —
переопределите их в `~/.zshrc` после строки `source`. Промпт показывает код
возврата последней команды и признаки контекста (`ssh`, `chroot`, `subshell`,
`use <venv/conda>`, `on <git-ветка>`).

## Плагины

По умолчанию подключаются `zsh-autosuggestions` и `zsh-syntax-highlighting`
(последним — это важно для подсветки). Список и порядок задаются в `~/.zshrc`
через функцию `plugin-load`; при первом запуске плагин клонируется
(`git clone --depth 1`) и добавляется в `fpath`.

Добавить плагин — допишите строку в `~/.zshrc`:

```zsh
plugin-load zsh-users/zsh-autosuggestions
```

Пиннинг версии — через `@<sha>`:

```zsh
plugin-load zsh-users/zsh-autosuggestions@85919cd1ffa7d2d5412f6d3fe437ebdbeeec4fc5
```

Каталог плагинов можно переопределить переменной `ZPLUGINDIR` — задайте её в
`~/.zshrc` **до** строки `source`, подключающей `zshrc`.

## Обновление и смена расположения

- Обновить конфигурацию: `git pull` в каталоге репозитория (при условии, что
  `~/.zshrc` ссылается именно на него).
- Обновить плагин: удалите его каталог в `plugins/` и запустите zsh заново.
- Сменить расположение: перенесите репозиторий и повторно запустите
  `install.sh` — путь в `~/.zshrc` будет обновлён.

## Удаление

```sh
"${XDG_DATA_HOME:-$HOME/.local/share}/rshell/install.sh" --uninstall
```

Скрипт удаляет `~/.zshrc`, только если он был установлен rshell (проверяется
маркер), и восстанавливает `~/.zshrc.bak`. Каталог плагинов не удаляется —
уберите его вручную, если он больше не нужен.
